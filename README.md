\## 目标



SpaceTally 是一款 Windows 桌面磁盘空间分析工具。用户选择任意本地目录后，可定位其下各级目录和文件的逻辑大小，快速发现异常占用。



\## 已确认的需求



\- 技术栈采用 Electron + React + TypeScript；使用 SQLite 作为本地数据库，界面默认跟随浅色系统主题，也支持手动切换深色。

\- 递归扫描整个选定目录，结果初始只展示一级节点；目录树可逐级展开，展开不重复扫描。

\- 根目录自身文件聚合为“根目录文件”节点，并与子目录一起参与总量统计。

\- 显示名称、逻辑大小、占比、文件数、子文件夹数；可按名称或大小排序、关键词搜索，并在资源管理器中定位。

\- 独立“大文件榜”显示全局前 20 个文件。

\- 扫描过程显示进度并可取消；取消后丢弃本次结果。每次完整扫描将结果写入 SQLite，保留最近 10 次记录（超过 10 次时删除最早记录）；历史记录展示扫描时间并可重新扫描。

\- 无权限或读取失败项跳过并提示；不跟随符号链接、联接点和其他目录重解析点。

\- 第一版不含删除、移动、清理、导入导出、管理员提权、网络路径或实际簇占用计算。



\## 本地数据



\- SQLite 记录扫描根路径、开始/结束时间、总大小、文件/目录数量、跳过项汇总、目录统计树和前 20 大文件榜。

\- 仅成功完成的扫描进入历史；取消或失败的扫描不覆盖历史记录。

\- 历史记录上限为 10 条，按完成时间倒序显示；写入第 11 条后清除最早的一条及其关联的目录和文件明细。



\## 2. 架构与技术栈



```text

React Renderer（展示与交互）

&#x20;         │ IPC / contextBridge

Preload（窄业务 API，隔离 Node 能力）

&#x20;         │

Electron Main（扫描、授权、SQLite、系统定位）

&#x20;  ├─ node:fs/promises

&#x20;  ├─ better-sqlite3

&#x20;  └─ Electron dialog / shell

```



技术栈为 Electron 37、React 19、TypeScript 5.8、Vite 7 和 SQLite（better-sqlite3）。Vite 构建渲染进程，TypeScript 编译主进程；`npm run dev` 启动开发环境，生产环境加载 `dist/renderer`。



分层原则是：Renderer 仅管理界面状态；Main 持有文件系统、数据库和系统调用权限；Preload 通过 `contextBridge` 仅暴露所需能力。这样既保持 UI 纯前端化，也避免页面直接获得任意本机文件访问能力。



\## 3. 扫描与安全路线



扫描器以深度优先递归执行：`readdir` 枚举目录，`lstat` 识别文件类型，普通文件累加大小和数量，子目录递归后向上聚合。每层目录的直接文件会合并为 `root-files` 虚拟节点；父目录大小包含该节点和所有子目录，且不重复计数。扫描期间维护一个最多 20 项的降序数组，因此无需保存全部文件明细即可得到大文件榜。



```text

选择并授权根目录 → realpath 建立根边界 → 递归扫描

&#x20;  ├─ 普通文件：累计并更新 Top 20

&#x20;  ├─ 子目录：递归、聚合

&#x20;  └─ 链接/路径解析变化/读取失败：记录 skippedItems 后跳过

→ 生成目录树与统计结果 → 成功时保存历史

```



每 300 个普通文件和扫描结束时上报进度；该进度表示已处理数量与累计字节，而非百分比。取消采用协作式标志位，递归和循环均会检查；在超大目录的单次 `readdir` 未返回前，取消可能延迟。取消或扫描失败不会保存结果。



安全上，Main 端只接受目录选择器或历史记录登记过的根路径；打开位置时也会验证目标在授权根内。路径先规范化，目录扫描同时结合 `lstat` 与 `realpath`，跳过符号链接以及解析路径变化或越出根目录的目录，防止循环和越界。当前并未显式拒绝 UNC、映射网络盘、`\\\\?\\\\` 等 Windows 特殊路径；“不支持网络路径”仍是产品约束，后续需要补充输入校验和更强的规范路径比较。



\## 4. 数据与交互



数据库位于 Electron `userData/disklens.sqlite`，启用 WAL。`scans` 表保存根路径、起止时间和完整 `result\_json`，按 `completed\_at DESC, id DESC` 保留 10 条。历史列表只读取元数据，点击后才加载完整目录树。读取历史会在本次进程恢复该根目录授权；删除历史不会撤销已加入内存集合的授权。



前端由 `App.tsx` 管理扫描结果、进度、历史、页面、主题及空间地图下钻栈：



\- \*\*目录树\*\*：递归行组件，显示大小、占比和计数；极小项可合并以减少噪声。

\- \*\*空间地图\*\*：当前层级显示主要节点及“更多”合并项，以 flex 布局和色深表达相对占用，支持下钻/返回或打开系统位置。

\- \*\*大文件榜与历史\*\*：直接消费扫描结果；支持加载、删除历史记录。



核心 IPC 包括 `folder:choose`、`scan:start/cancel`、进度/完成/取消事件、`history:\*` 和 `path:open`。Main 使用 `scanning` 标志避免并发扫描冲突。
