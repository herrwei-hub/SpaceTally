# SpaceTally

<img src="assets/icon.png" alt="SpaceTally 图标" width="88">

SpaceTally 是一款面向 Windows 的本地磁盘空间分析工具。选择一个目录后，它会统计文件的**逻辑大小**，帮助你找出占用空间较多的目录和文件。扫描只读取文件信息，不修改原文件。

> 当前为开发中的核心扫描版。SQLite 历史、空间地图、搜索排序和安装包尚未实现。

## 已实现

- 通过系统目录选择器选择本地目录，递归扫描文件和子目录。
- 汇总各级目录的逻辑大小、文件数和子目录数；目录树可逐级展开，展开时不会重新扫描。
- 将每个目录中的直接文件显示为“根目录文件”或“本目录文件”汇总项。
- 显示全局前 20 个大文件，以及扫描中的已处理数量、累计大小和当前路径。
- 可取消扫描；读取失败或无权限的子项会跳过并在结果中提示。
- 不跟随符号链接或联接点，拒绝网络、设备及映射网络盘路径。

## 快速开始

需要 Windows、Node.js 和 npm。在项目根目录运行：

```bash
npm ci
npm run dev
```

在应用中选择本地目录，再点击“开始扫描”。扫描完成后可查看目录结构、大文件榜和跳过项目。

其他开发命令：

| 命令 | 用途 |
| --- | --- |
| `npm run typecheck` | 检查主进程与界面的 TypeScript 类型 |
| `npm test` | 运行核心扫描器测试 |
| `npm run build` | 构建 Electron 主进程和渲染界面到 `dist/` |

`dist/` 和 `node_modules/` 已由 `.gitignore` 排除，不需要提交到仓库。目前没有安装包脚本；`npm run build` 只生成应用代码。

## 扫描口径与限制

- 大小采用文件逻辑字节数，不代表磁盘实际簇占用；硬链接会按路径分别统计。
- 文件数和子目录数是该目录下的后代总数。目录自身不计入自己的子目录数。
- 进度显示已处理计数，不显示无法准确预估的完成百分比。
- 无权限或读取失败的子项不会计入大小，结果会显示跳过项数量；根目录不可读取时扫描失败。
- 取消会丢弃本次部分结果。正在等待单次文件系统调用返回时，取消可能短暂延迟。
- 当前扫描结果只保存在运行中的窗口内。关闭应用后不会保留，也不会自动随文件变化更新。
- 第一版不会删除、移动或清理文件，不提权，也不扫描网络路径。

## 技术结构

```text
React + TypeScript 界面
        │ 业务 API / IPC
Electron Preload（隔离 Node 能力）
        │
Electron Main（目录授权、扫描与系统调用）
        └─ node:fs/promises
```

技术栈：Electron 37、React 19、TypeScript 5.8、Vite 7。SQLite 是下一阶段的本地历史存储方案，当前代码尚未引入数据库依赖。
